GANPATI MURTI STORE WEBSITE

Pages: index.html, shop.html, about.html, contact.html
Assets/code: css/style.css and js/script.js

RUN:
1. Extract the ZIP folder.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.

CUSTOMISE:
- Open js/script.js and replace WHATSAPP_NUMBER with your real number in international format, digits only (India example: 919876543210).
- Edit the products array in js/script.js to change product names, prices, categories and image URLs.
- Replace placeholder phone, email and address in the HTML pages.
- Replace sample image URLs with your own product photos. The images currently load from online URLs, so internet access is needed.

NOTES:
This is a front-end demo. Cart data is stored in the browser's localStorage and enquiry details are opened in WhatsApp. There is no real payment gateway, inventory system, database or order backend. Verify that the images match your actual murti products before publishing.
